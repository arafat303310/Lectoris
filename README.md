# Lectoris

Lectoris (formerly ApplyHub Uganda) is a comprehensive higher education platform designed to connect Ugandan students with universities, scholarships, and educational services.

## Features

- **University Discovery**: Browse and apply to top Ugandan universities with direct portal links.
- **Scholarships**: Find and save local and international scholarship opportunities.
- **Educational Services**: Access professional assistance for applications, essays, and resumes.
- **AI Course Advisor**: Get personalized guidance on courses and universities.
- **User Dashboard**: Manage your saved items and service requests.

## Tech Stack

- **Frontend**: React, TypeScript, Vite, Wouter, TanStack Query, Tailwind CSS, Radix UI.
- **Backend**: Express.js, Node.js, Passport.js (Replit OIDC & Local Auth).
- **Database**: PostgreSQL with Drizzle ORM.
- **Styling**: Midnight Navy, Academic Gold, Oxford Silver design system.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Set up environment variables (DATABASE_URL, SESSION_SECRET).
3. Push the database schema:
   ```bash
   npm run db:push
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
